# Examples

The repository includes one curated national case study:

- [Baseline constrained case (`p = 200`)](baseline_p200/README.md)

It contains the principal selected-asset and grid-connection CSVs, three representative plots, exact run metadata, a human-readable model summary, and a verification script. Large diagnostic tables and redundant coordinate exports are omitted to keep the Git repository compact.

Generated smoke-test and sensitivity-run directories belong under the repository-level `results/` directory, which is intentionally ignored by Git.
